ClipForge Privacy Policy

Last updated: November 18, 2026

ClipForge is a personal desktop application used by its operator to edit video clips and send them to his own social media accounts.

What data ClipForge accesses

  • TikTok: with the user's permission through TikTok Login Kit, ClipForge receives an access token, the account's open ID, display name and avatar (scope user.info.basic), and the ability to upload videos to the user's TikTok inbox as drafts (scope video.upload).
  • YouTube: with the user's permission through Google OAuth, ClipForge receives a token with the youtube.upload scope, used only to upload videos the user selects to the user's own channel. ClipForge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. ClipForge uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
  • Instagram: with the user's permission through Meta, ClipForge receives a token used only to publish Reels the user selects to the user's own Instagram professional account.
  • Video files the user chooses to edit and upload.

How data is used

The display name and avatar are shown in the app so the user can see which account is connected. The access token is used only to upload videos the user selects. ClipForge does not read, collect or analyze other TikTok content or other users' data.

Storage and sharing

Tokens and videos are stored only on the user's own computer. ClipForge has no servers, does not sell or share data with anyone, and does not use data for advertising.

Deleting data

The user can disconnect ClipForge at any time: in TikTok (Settings → Security and permissions → Apps and services), Google (myaccount.google.com/permissions) or Facebook/Instagram (Settings → Apps and websites), and delete the local token files. This removes all data ClipForge holds.
